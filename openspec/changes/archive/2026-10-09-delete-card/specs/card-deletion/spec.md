## Purpose
Описывает поведение системы при удалении карточки с доски пользователем.

## ADDED Requirements

### Requirement: Наличие элемента управления удалением
Каждая карточка на доске SHALL отображать видимый элемент управления (кнопку-крестик) для инициирования удаления.

#### Scenario: Отображение кнопки удаления
- **WHEN** карточка отображается на доске
- **THEN** в её правом верхнем углу видна кнопка удаления (×)

### Requirement: Удаление карточки по запросу
Система SHALL удалять карточку с сервера и скрывать её с доски при нажатии на кнопку удаления.

#### Scenario: Успешное удаление карточки
- **WHEN** пользователь нажимает кнопку удаления на карточке
- **THEN** отправляется DELETE-запрос на сервер с ID карточки
- **AND** после успешного ответа карточка исчезает с доски без перезагрузки страницы

#### Scenario: Удаление выполненной карточки
- **WHEN** пользователь нажимает кнопку удаления на карточке, помеченной как выполненная
- **THEN** карточка удаляется так же, как и обычная карточка
