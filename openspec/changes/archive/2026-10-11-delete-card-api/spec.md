# Спецификация: delete-card-api

## Требования

### REQ-1. Роут удаления карточки
Сервер ДОЛЖЕН обрабатывать `DELETE /cards/:id`.
Идентификатор карточки берётся из параметра пути `req.params.id`.

### REQ-2. Статус-код успешного удаления
Сервер ДОЛЖЕН отвечать статусом **204 No Content** без тела ответа.

**Обоснование:** клиентская функция `deleteCard` возвращает `Promise<void>` и не использует тело ответа. Статус 204 семантически означает "успешно выполнено, возвращать нечего" — это точнее, чем 200 с пустым телом.

### REQ-3. Удаление несуществующей карточки
Если карточки с указанным `id` нет в массиве, сервер ДОЛЖЕН отвечать статусом **404** и JSON-телом:
```json
{ "error": "Карточка не найдена" }
