# Proposal: server-side-done-filter

## Контекст

На Kanban-доске есть переключатель «скрыть выполненные» в шапке доски. Сейчас он работает на клиенте: сервер отдаёт все карточки через `GET /cards`, а колонка отфильтровывает выполненные на клиенте. Это неэффективно — при большом количестве карточек браузер получает и обрабатывает лишние данные.

Тикет KAN-5: перенести отбор карточек на сервер, чтобы база возвращала только нужные строки.

## Проблема

- Серверный запрос `GET /cards` всегда возвращает все карточки без фильтрации.
- Клиентский компонент `BoardColumn` отсеивает выполненные карточки самостоятельно.
- Переключатель в `BoardHeader` меняет состояние, но не влияет на запрос к серверу.

## Решение

Добавить параметр строки запроса `done` со значениями `true` и `false` к эндпоинту `GET /cards`.

- Включённый фильтр «скрыть выполненные» отправляет `done=false`.
- Выключенный фильтр — параметр отсутствует.
- Значение `done=true` означает «показать только выполненные» (на будущее).
- Любое другое значение параметра отклоняется кодом 400.

## Scope

### In scope

- **Сервер**
  - Репозиторий: функция `findAll(hideDone: boolean)` с SQL-условием `WHERE is_done = $1`.
  - Сервис: функция `getAll(hideDone: boolean)` передаёт параметр в репозиторий.
  - Контроллер: `getCards` читает `req.query.done`, валидирует, передаёт в сервис.
  - Роутер: без изменений (параметр строки запроса, не путь).
- **Клиент**
  - `fetchCards` принимает параметр `hideDone: boolean`, передаёт его как `?done=false`.
  - `App` хранит состояние `hideDone` и передаёт его в `fetchCards`.
  - Ключ `useQuery` включает `hideDone`, чтобы при переключении запрос перезапускался.

### Out of scope

- Аутентификация и авторизация (пока один пользователь).
- Фильтры по приоритету, по владельцу, по дате.
- Пагинация.
- WebSocket-синхронизация.

## Impact

- **Сервер:** репозиторий (`cards.repository.ts`), сервис (`cards.service.ts`), контроллер (`cards.controller.ts`).
- **Клиент:** `client/src/api/cards.ts`, `client/src/App.tsx`.
- **Существующие роуты** — без изменений, `GET /cards` остаётся тем же адресом.
- **Схема БД** — без изменений, используется существующее поле `is_done`.
