# Proposal: cards-counter

## Why

На доске не видно, сколько на ней карточек — приходится считать вручную, особенно когда карточек много и колонка не помещается на экране. Пользователю нужно быстро оценить объём задач, не открывая доску и не пересчитывая карточки.

## What

- В шапке доски (`BoardHeader`) рядом с названием отображается счётчик **общего** числа карточек на доске в формате `Канбан-доска (N)`.
- Счётчик показывает ОБЩЕЕ количество всех карточек, независимо от значений полей `isDone` и `isUrgent`.
- Счётчик обновляется автоматически при загрузке карточек через React Query.
- При `N = 0` отображается `Канбан-доска (0)`.

## Scope

### In scope

- Изменение компонента `BoardHeader` — приём пропса `totalCards: number` и рендер счётчика.
- Проксирование `cards?.length` из `App.tsx` в `BoardHeader`.
- Стилизация счётчика (CSS-модуль `BoardHeader.module.css`).

### Out of scope

- Разбивка счётчика по статусам (isDone / isUrgent).
- Фильтрация счётчика.
- Несколько досок — пока одна доска, название зашито.
- Реалтайм-обновления вне React Query refetch.

## Impact

- `App.tsx` — добавить проп `totalCards` в `<BoardHeader />`.
- `BoardHeader.tsx` — добавить проп `totalCards`, рендер `<span>` со счётчиком.
- `BoardHeader.module.css` — добавить стиль `.count`.
