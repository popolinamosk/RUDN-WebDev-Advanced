# Spec: cards-counter

## Requirements

### REQ-1. Отображение счётчика

Компонент `BoardHeader` обязан отображать рядом с названием доски общее количество карточек в формате `Канбан-доска (N)`, где `N` — число карточек.

- При `N = 0` отображается `Канбан-доска (0)`.
- Счётчик отображается сразу после названия доски, отделён одним пробелом перед открывающей скобкой.

**Примеры:**
- 5 карточек → `Канбан-доска (5)`
- 0 карточек → `Канбан-доска (0)`
- 42 карточки → `Канбан-доска (42)`

### REQ-2. Источник данных

Счётчик получает число карточек через проп `totalCards` из родительского компонента `App.tsx`.

- `App.tsx` передаёт `cards?.length ?? 0` в `BoardHeader`.
- Значение берётся из данных React Query (`useQuery(["cards"])`).

### REQ-3. Обновление

Счётчик обновляется автоматически при каждом изменении данных карточек:

- При первичной загрузке (`fetchCards`).
- При создании новой карточки (`createCard` → `invalidateQueries`).
- При любом другом изменении данных, вызывающем рефетч.

### REQ-4. Визуальное оформление

Счётчик визуально отделён от названия доски:

- Отделён одним пробелом от текста названия.
- Выделен цветом `var(--text-muted)` (как заголовок колонки).
- Шрифт немного мельче названия (`font-size: 14px`).

### REQ-5. Счётчик показывает ОБЩЕЕ количество всех карточек

Счётчик учитывает ВСЕ карточки на доске без фильтрации по статусу или приоритету.

**WHEN** карточки на доске имеют разные значения полей `isDone` и `isUrgent`,
**THEN** счётчик показывает сумму всех карточек, игнорируя значения `isDone` и `isUrgent`.

**Пример:**
- 3 карточки с `isDone: false` + 2 карточки с `isDone: true` → счётчик показывает `5`.
- 1 карточка с `isUrgent: true` + 4 карточки с `isUrgent: false` → счётчик показывает `5`.
